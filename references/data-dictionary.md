# Data dictionary — `player_fixtures.parquet`

Generated by `uv run python -m fpl.dataset main`. Edit `fpl/dataset.py`, not this file.

Grain is one row per player per fixture. The unique key is
`(season, element, GW, fixture)`; `(element, GW)` is not unique, because of double
and triple gameweeks.

| Column | Type | Source | Meaning | Seasons populated |
|---|---|---|---|---|
| `season` | String | derived | Season label, e.g. 2025-26 | all |
| `kickoff_time` | Datetime(time_unit='us', time_zone='UTC') | merged_gw.csv | Kickoff, UTC; every asof cutoff keys on this | all |
| `code` | Int32 | players_raw.csv | Stable cross-season player id; all cross-season joins use this | all |
| `position` | String | merged_gw.csv / players_raw.csv | GK, DEF, MID, FWD, or AM | all |
| `team` | Int32 | fixtures.csv / players_raw.csv | Season-scoped id of the player's team | all |
| `team_name` | String | master_team_list.csv / teams.csv | Club name for that season | all |
| `GW` | Int32 | merged_gw.csv | Gameweek number | all |
| `fixture` | Int32 | merged_gw.csv | Season-scoped fixture id | all |
| `element` | Int32 | merged_gw.csv | Season-scoped player id; never a cross-season key | all |
| `opponent` | Int32 | merged_gw.csv | Season-scoped id of the opposing team | all |
| `was_home` | Boolean | merged_gw.csv | Player's team was at home | all |
| `minutes` | Int32 | merged_gw.csv | Minutes played | all |
| `starts` | Int32 | merged_gw.csv | 1 if the player started; null before 2022-23 | 2022-23, 2023-24, 2024-25, 2025-26 |
| `goals_scored` | Int32 | merged_gw.csv | Goals scored | all |
| `assists` | Int32 | merged_gw.csv | Assists | all |
| `clean_sheets` | Int32 | merged_gw.csv | 1 if a clean sheet was credited | all |
| `goals_conceded` | Int32 | merged_gw.csv | Goals conceded while on the pitch | all |
| `saves` | Int32 | merged_gw.csv | Saves made | all |
| `bonus` | Int32 | merged_gw.csv | Bonus points awarded, 0-3 | all |
| `bps` | Int32 | merged_gw.csv | Bonus Points System score | all |
| `yellow_cards` | Int32 | merged_gw.csv | Yellow cards | all |
| `red_cards` | Int32 | merged_gw.csv | Red cards | all |
| `own_goals` | Int32 | merged_gw.csv | Own goals | all |
| `penalties_missed` | Int32 | merged_gw.csv | Penalties missed | all |
| `penalties_saved` | Int32 | merged_gw.csv | Penalties saved | all |
| `expected_goals` | Float64 | merged_gw.csv | Opta xG; null before 2022-23 | 2022-23, 2023-24, 2024-25, 2025-26 |
| `expected_assists` | Float64 | merged_gw.csv | Opta xA; null before 2022-23 | 2022-23, 2023-24, 2024-25, 2025-26 |
| `expected_goals_conceded` | Float64 | merged_gw.csv | Opta xGC; null before 2022-23 | 2022-23, 2023-24, 2024-25, 2025-26 |
| `clearances_blocks_interceptions` | Int32 | merged_gw.csv | CBI count; present 2016-17 to 2018-19 and 2025-26 only | 2016-17, 2017-18, 2018-19, 2025-26 |
| `tackles` | Int32 | merged_gw.csv | Tackles; same seasons as CBI | 2016-17, 2017-18, 2018-19, 2025-26 |
| `recoveries` | Int32 | merged_gw.csv | Recoveries; same seasons as CBI | 2016-17, 2017-18, 2018-19, 2025-26 |
| `defensive_contribution` | Int32 | merged_gw.csv | Defcon action count, position-specific; 2025-26 only | 2025-26 |
| `total_points` | Int32 | merged_gw.csv | Points actually scored; the eval target | all |

`xP` is dropped rather than lagged, and no set-piece column is carried. Both are
deliberate exclusions — see `references/known-issues.md`.
